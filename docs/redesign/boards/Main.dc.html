Design language
v1 · October 2026

01

Near-black ground, one acid accent. Colour marks state and action, never decoration.

02

Condensed display type for names. Mono for every date, set time and count. All names uppercase, artists included. Nothing below 11px.

03

Squared corners and hairlines. No gradients, no glow, no emoji icons.

04

Acid has two jobs: what is yours (picked, rated, followed, attended) and the one primary action per screen. Lilac means going. Orange means clash.
